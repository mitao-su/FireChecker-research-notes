# FireChecker 小火焰识别研究记录

这份仓库只记录模型改进思路、离线对照结果和后续建议，方便协作者独立阅读。仓库不包含比赛图片、人工标签、提交结果文件、模型权重或任何预计算输入。

## 当前结论

- 当前正式模型在平台反馈中的 F1 是 **0.9602**。
- 正式模型和现有提交包保持不变，本轮离线试验没有消耗新的平台提交次数。
- 本轮目标是提高画面中很小、很隐蔽的明火召回率，例如地面燃烧物和画面边角的火炬。
- 只有看见明火才算正例；只看见烟不算正例。
- 本仓库中的离线分数来自人工复核记录和源数据小样本，不能当作平台隐藏分数。
- 三个候选中，`spatial` 在离线复核记录上最好，但提升幅度有限，尚不足以证明平台成绩会提升。

## 结果边界

比赛输入的真实标签未知。人工复核记录仍可能有错，同一场景的相邻画面也可能同时出现在不同折中，因此离线结果只能用来筛选方向。任何新模型都需要平台反馈才能确认是否真的提升。

当前正式包仍是唯一已确认成绩的版本。`spatial` 只作为下一次提交前的候选研究方向，不会自动替换正式包。
